# OpsPilot

OpsPilot is a personal learning project for building practical skills in Python, networking, Linux, Git, APIs, cloud, DevOps, and infrastructure troubleshooting.

The goal is to build a small but realistic project using professional engineering practices while learning the technologies along the way.

## Progress

### Phase 0 - Engineering Workspace ✅

- Python virtual environment
- Git and GitHub workflow
- `.gitignore`
- Dependencies and `requirements.txt`
- Project structure
- Multi-PC development workflow

### Phase 1 - Python + CLI Foundation ✅

- Python fundamentals
- Input and validation
- Functions and return values
- Lists, dictionaries, and loops
- Exception handling
- Modules and imports
- Exit codes
- Basic separation of responsibilities
